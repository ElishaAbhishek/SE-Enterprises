---

## 🚀 Quick Start in VS Code

### Option 1: Using the Terminal in VS Code
1. Open this folder (`SE`) in **VS Code** (`File` > `Open Folder...`).
2. Open the integrated terminal (`Ctrl + ~` or `Terminal` > `New Terminal`).
3. Run:
   ```bash
   npm run dev
   ```
4. Click on the local link (e.g. `http://localhost:3000`) or it will open automatically in your browser!

### Option 2: 1-Click Launch (No commands needed)
- Simply double-click the file `start-website.bat` in File Explorer or VS Code.
